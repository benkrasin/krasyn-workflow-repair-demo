## Run the synthetic demonstration

Requires Python 3; no packages, API keys or network calls.

```sh
python3 clean_export.py sample.csv output
```

Open `output/report.html`. `clean.csv` contains usable normalized rows; `audit.json` preserves every original row and identifies duplicates and conflicts. The sample gives 8 input rows: 4 accepted, 3 needing review and 1 exact duplicate. Formula prefixes are escaped in the spreadsheet output.

This is an export-cleanup demonstration. It does not prove an n8n deployment, vendor integration, customer outcome or ability to handle arbitrary data. CSV rules are agreed for each engagement.
